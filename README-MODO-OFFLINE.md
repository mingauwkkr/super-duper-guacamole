# Modo Offline — Site de dependência tecnológica

Trabalho da Kodland sobre UI, UX, animações CSS e widgets de previsão do tempo.

## Abrir
Abra `index.html` no navegador. Os arquivos `style.css` e `script.js` precisam estar na mesma pasta.

## Requisitos
- Interface moderna, responsiva, com navegação e visual consistente.
- `@keyframes color-change` com `h1:hover`, efeitos de hover nos botões e cartões.
- Acessibilidade: texto legível, teclado, suporte a movimento reduzido.
- Widget de previsão do tempo em `iframe` na seção Clima.
- Dicas interativas e checklist em JavaScript.

## Fonte do widget
[24WeatherTomorrow](https://24weathertomorrow.com/pt-br/widget-builder/). O widget usa a cidade de São Paulo (SP), configurada pelo serviço.
